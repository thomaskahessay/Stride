## Tech Stack
- Swift 5.10+ / SwiftUI
- SwiftData (local persistence, iCloud later)
- HealthKit (read-only, post-run passive sync)
- UserNotifications framework
- iOS 18+ minimum (user said "iOS 26" — noting that iOS 26 is not yet released as of March 2026; targeting iOS 18+ as latest stable)
- Xcode 16+

## Key Architectural Decisions
- MVVM throughout — Views are dumb, ViewModels own state
- @Observable macro (not ObservableObject) for view models
- SwiftData @Model for all persisted data
- No network layer in v1 (all local)
- HealthKit reads happen via background query on app foreground
- Training plan stored as array of WorkoutDay objects on device
- Notifications scheduled locally via UNUserNotificationCenter
